# Сосновый берег — демо интерактивного генплана

Интерактивная карта коттеджного посёлка для сайта застройщика: статусы участков, фильтры, карточка участка с расстояниями до леса и воды, запись на просмотр, подложка OpenStreetMap.

Посёлок, участки, цены и кадастровые номера выдуманы. Лес и вода настоящие, по данным © участники OpenStreetMap (ODbL), место — поле у Озернинского водохранилища.

## Файлы
- `index.html` — готовая страница (её отдаёт GitHub Pages).
- `data/plots.geojson` — участки: номер, площадь, цена, статус, кадастровый №.
- `data/context.geojson` — лес, вода, улицы, пляж, точки интереса.
- `data/site.json` — контуры леса и воды, распознанные из тайлов OSM.
- `prepare_site.py` → `gen_data.py` → `build.py` — сборка: площадка → участки → страница.

## Как поменять данные
1. Откройте `data/plots.geojson` в QGIS, отредактируйте и сохраните в GeoJSON (EPSG:4326).
2. Выполните `python build.py`.
3. Локально: `python -m http.server`, затем http://localhost:8000.
